# ADR-0002: 転送路はプレーンテキストに限定する

- Status: Accepted
- Date: 2026-09-18

## 背景

アプリと LLM の間にはネットワーク接続がない。運ぶのは利用者で、通り道は共有シートとクリップボードしかない。
チャット UI はテキスト以外をほぼ確実に落とす。

## 決定

往復のペイロードは **UTF-8 のプレーンテキストのみ**とする。バイナリ・添付・独自 MIME は使わない。
構造は JSON 封筒（[UCP-1](../protocol.md)）で表し、コードフェンスは付けるが**探索の根拠にはしない**。
受信側はセンチネルキー `"ucp"` + 括弧の対応走査を主経路とする。

## 理由

Claude のコピーボタンはフェンスを剥がすことがあり、共有シート経由の文字列も素のテキストになる。
フェンスに依存した実装は環境ごとに壊れる。

## 結果

- 抽出器が唯一の複雑な箇所になるため、テストをここに集中させる。
- 画像・ファイルのやりとりは当面スコープ外。
